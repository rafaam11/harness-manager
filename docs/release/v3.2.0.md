# v3.2.0 — 화면 정리

기능은 그대로 두고, v2 화면과 v3 화면이 섞여 있던 겉모양을 하나의 체계로 맞췄습니다.

## 바뀐 점

- **사이드바**: 글자 목록 대신 아이콘 아래 짧은 이름을 붙인 좁은 열로 바꿨습니다.
- **업데이트 배지**: 사이드바 아래에서 타이틀바 오른쪽(셋업 위저드 버튼 옆)으로 옮겼습니다.
- **Provider 필터**: 사이드바의 전역 필터를 없앴습니다. 카탈로그와 설정 편집기가 화면 안의 탭(전체·Claude·Codex)으로 고르고, 고른 값을 화면마다 기억합니다.
- **모든 화면이 같은 부품을 씁니다**: 화면 머리, 탭(화살표·Home·End 키 이동), 툴바, 패널, 상태 태그, 상태 점, 배너, 빈 상태, 체크박스.
- 색은 테마 토큰으로만 씁니다. 상태 배경과 카탈로그 종류 배지 색을 다크·라이트 두 테마에 맞게 정리했습니다.
- 고르기 상자(외부 API 필터 등)와 설정 편집기 툴바가 앱 색을 따릅니다.

## 호환성

- v3.1.0에서 자동 업데이트로 올라옵니다. 설정·상태 파일에는 영향이 없습니다.
- 사이드바에서 고르던 provider 필터 값은 이어지지 않습니다. 처음 열면 "전체"로 시작합니다.

## 검증

- `npm test`: 테스트 파일 45개, 테스트 258개 통과(새 공통 컴포넌트 테스트와 스타일 계약 테스트 포함)
- `npm run typecheck`, `npm run build`, `electron-builder --win` 통과
- 개발 앱에서 9개 화면(상태판·설치·카탈로그·정리·설정 편집기·가져오기·외부 API·위저드·상세 대화상자)을 다크·라이트 두 테마로 캡처해 확인
- 개발 앱에서 정리 dry-run, 설정 편집기 provider 전환, 위저드 미리보기 단계까지 진행 확인(설정 저장과 위저드 실행은 실제 홈을 건드려 GUI에서 누르지 않음)
- 패키지 앱(`release/win-unpacked`)에서 사이드바 7개 항목과 타이틀바 업데이트 배지 확인
