# v5.0.0 — CLI별 설정과 mod를 한곳에서 관리

v5.0.0은 Windows CI에서 옵션 저장 직후의 이탈 확인 문제를 발견해 공개하지 않았습니다. 수정한 [v5.0.1](v5.0.1.md)을 사용하세요.

**이 PC**를 공통 / Claude Code / Codex로 나눴습니다. 공통 스킬·지침은 함께 관리하고, CLI마다 다른 설정과 확장은 해당 탭에서 편집합니다. 검색과 선택을 기억하며 작은 창에서는 상세를 겹쳐 엽니다.

- **설정:** 공식 설정 목록을 검색하고 문자열·숫자·선택값·배열·객체를 편집합니다. PC 저장값·내 설정·기본값·출처를 구분하고 기본값 사용·관리 해제를 제공합니다. 알 수 없는 키와 조직·인증·프로젝트·Codex 프로필 설정은 읽기 전용입니다.
- **확장:** 미설치 상태에서도 Claude mod 5개와 Codex jinmin-codex를 확인합니다. 설치·켜기·끄기와 공개된 옵션을 검토 후 적용합니다. Claude 옵션은 실제 `pluginConfigs[pluginId].options`에 저장합니다. 설치·활성·hook 신뢰·현재 세션 실행을 구별하고 MCW와 대체 기능의 차이를 표시합니다.
- **적용·복원:** 한 번 검토한 뒤 기준과 PC 파일을 함께 저장·복원합니다. JSON의 선택한 경로, TOML의 선택한 값만 수정합니다. 배열은 정확히 교체하고 기본값 사용은 해당 키를 제거합니다. 충돌이나 외부 설치 실패 시 기준 저장을 보류합니다.
- **동기화:** doctor/install/capture와 수동 수신이 같은 설정 정의를 사용합니다. PC 고유 경로는 로컬 파일에 분리하고 기본 이동 대상에서 제외합니다. 새 설정 변경은 자동 수신하지 않습니다.

## 호환성

새 CLI 설정을 편집한 이동 파일은 **version 3**입니다. 기존 version 1·2는 계속 읽으며 편집하지 않은 프로필을 자동 변환하지 않습니다. 새 설정을 공유하기 전에 동기화하는 모든 PC를 v5 이상으로 업데이트하세요. 구형 앱은 version 3을 쓰기 전에 거절합니다.

확장을 켜도 현재 세션의 실행이나 Codex hook 신뢰를 승인한 것은 아닙니다. 새 세션에서 확인해야 합니다. 외부 설치 명령은 자동 복원하지 않으며 파일 변경만 변경 기록에서 복원합니다. 토큰·로그인 정보는 저장하거나 전송하지 않습니다.

## 검증

격리된 Windows 테스트 홈에서 단위·계약 테스트, 타입 검사와 프로덕션 빌드를 확인했습니다. 실제 Electron에서 첫 설정 편집과 개인 사본 생성, Claude·Codex 설정 저장, 배열 편집, HUD 옵션 저장과 변경 기록 복원을 검증했습니다. 1280×800·900×600 및 125% 확대에서 바깥 스크롤과 적용 버튼 위치를 검사했습니다. 원격 수신은 로컬 Git 원격으로 확인하고 실제 계정·유료 모델·사용자 홈의 설정은 변경하지 않았습니다.
