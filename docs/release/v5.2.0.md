# v5.2.0 — 반복되던 설정 화면을 표로 정리하고 GitHub 동기화를 한 화면으로

항목마다 같은 입력칸과 패널이 반복되던 화면을 표로 바꿨습니다. 공통 속성은 열 머리에 한 번만 나오고, 명령과 diff 같은 세부 내용은 행을 펼쳐서 봅니다. 두 화면에 나뉘어 있던 GitHub 동기화 기능은 동기화 화면으로 모았습니다.

- **고급 프로필:** 설치 항목과 관리 설정을 표로 편집합니다. 설치 항목·관리 설정·개인 설정·파일 이동·프로필 관리 탭으로 나누고, 화면 아래 저장 막대와 미리보기 대화상자로 저장합니다.
- **설치·위저드:** 항목마다 패널을 쌓던 목록을 표 하나로 바꿨습니다. 할 일이 39개인 PC의 900×600 창에서 설치 화면 스크롤 높이가 4948px에서 2169px로 줄었습니다. 위저드 5·6단계의 결과와 로그인 안내도 표로 보여 줍니다.
- **가져오기:** 항목을 표로 보여 주고, 오류와 노출 경고가 있는 행은 눌러 보지 않아도 펼쳐집니다. 비공개 낱말 관리는 접어 두고 위쪽에는 프로필 선택만 남겼습니다. 개인 프로필 만들기는 위저드와 고급 프로필에서 합니다.
- **GitHub 동기화 일원화:** GitHub 연결과 보내기·받기는 동기화 화면에서 합니다. 고급 프로필의 "동기화·이동" 탭은 "파일 이동"으로 바뀌었습니다. 파일별 충돌 선택, 진행 로그, 연결 전 확인 대화상자를 동기화 화면으로 옮겼습니다.
- **충돌 해결 뒤 안내:** 충돌을 고른 결과는 내 설정에만 저장되고 이 PC에는 아직 적용되지 않습니다. 동기화 화면이 이 사실을 알리고 설치 화면으로 안내합니다.

## 호환성

프로필·이동 파일 형식과 기존 설정, CLI 명령은 바뀌지 않습니다. 기억된 탭 선택도 유지됩니다. 동기화 동작은 그대로이며 강제 push와 원격 자동 적용은 하지 않습니다.

## 알려진 한계

- 고급 프로필 표에서 긴 값이 입력칸에서 잘릴 수 있습니다. 예를 들어 `pluginConfigs…` 키와, 900px 폭의 패키지 ID와 설치 스크립트 URL입니다.
- 위저드에서 "다음"을 눌러도 스크롤 위치가 유지되어 다음 단계가 중간부터 보일 수 있습니다. 이전 버전부터 있던 동작입니다.
- 위저드 3단계는 열 머리가 생기면서 스크롤 높이가 1523px에서 1737px로 조금 늘었습니다.

## 검증

Windows에서 단위·계약 테스트 432개, 타입 검사, 프로덕션 빌드와 임시 홈의 실제 Electron E2E 2건을 확인했습니다. 격리된 Electron 화면을 캡처해 설치, 가져오기, 위저드, 동기화, 파일 이동 탭의 표시와 1280×800·900×600 창의 스크롤 높이를 확인했습니다. 실제 GitHub 원격에서 충돌을 일으켜 보지는 않았고, 파일별 충돌 선택은 IPC를 모의한 테스트로 확인했습니다. 실제 개인 프로필은 업로드하지 않았습니다.
