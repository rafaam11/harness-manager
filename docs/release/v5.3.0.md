# v5.3.0 — CLI 인식 목록과 범위별 진단, 예제 검사와 PC 상태 공유

첫 화면을 새 터미널 CLI가 인식하는 항목 중심으로 바꿨습니다. 설치 파일·활성 설정·CLI 인식·예제 실행 결과를 구분하며, 인식을 확인하지 못한 항목은 사용 가능으로 표시하지 않습니다.

- **CLI 인식 목록:** 첫 방문은 Codex이며 마지막 CLI 선택과 검색을 기억합니다. Codex의 프롬프트 분석을 구조화된 `app-server skills/list` 조회로 교체했습니다. CLI에서만 발견한 플러그인 스킬도 포함하고, 실제 경로와 플러그인 식별자로 동명 항목을 구분합니다. 인식됨·비활성·미검증·공유 기준 제외 필터와 출처 표시를 제공합니다.
- **전역·프로젝트 진단:** 프로젝트는 main의 폴더 선택기로 고르고 파일은 읽기만 합니다. 검사 시각과 CLI 버전, 경로, 소속 플러그인을 보여 줍니다. 검사 결과를 범위별로 보관하고 설정·스킬 내용이 바뀌면 재확인 필요로 표시합니다. 실패·취소 시 이전 성공 결과와 실패 사실을 함께 남깁니다. 기본 조회는 모델이나 MCP 연결 검사를 실행하지 않습니다.
- **확인에서 수정으로:** 플러그인 소속 스킬은 확장 관리로 연결하고 시스템 스킬의 편집·복사를 막습니다. 공유 기준 제외 여부를 별도로 표시합니다. 동기화 충돌을 선택한 뒤에는 병합한 기준으로 PC 적용 계획을 다시 준비해 검토하며, 최종 적용 전까지 기준·PC 파일을 쓰지 않습니다.
- **제한된 예제 검사:** 모델과 생성·실행 각각의 추정 비용·시간 제한을 고른 뒤 예제 생성 → 계획 검토 → 실행 → 산출물 확인으로 진행합니다. 현재 Claude의 도구·MCP 차단 텍스트 예제를 지원합니다. 임의 명령·외부 연결·지원하지 않는 검증 조건은 거절하며, 스킬 지문 변경·취소·시간 초과·출력 상한·인증 오류를 처리합니다. 본문 제공 증거와 텍스트 검증을 실행 종료 여부와 구분하고 최근 기록을 로컬에 보관합니다.
- **PC별 마지막 보고:** 무작위 PC ID와 직접 정한 별칭을 사용합니다. 전송 내용을 검토한 뒤 같은 비공개 저장소의 PC별 파일로 수동 공유합니다. 보고에는 식별자·버전·확인 상태와 시각만 담고 경로·프로젝트별 결과·지침·인증 정보·프롬프트·로그는 제외합니다. 다른 PC의 마지막 보고와 현재 PC·공유 기준의 차이를 비교하며, 보고 수신으로 설정을 적용하지 않습니다.
- **작은 창과 작업 우선순위:** 36px 목록 행과 높이에 맞춘 페이지를 유지하며 좁은 창에서 도구 모음을 줄바꿈합니다. 수동 적용·복원은 진행 중인 메타데이터 진단을 취소하고 정리한 뒤 실행합니다.

## 호환성

기존 프로필·이동 파일 형식과 CLI 명령은 유지합니다. 진단 기록·예제 기록·PC 보고는 공유 설정 정의와 별개이며 기존 자동 적용 판단에 포함하지 않습니다. PC 보고 전송은 공유 기준을 한 번 보낸 비공개 프로필 저장소에서 사용할 수 있습니다. 강제 push는 사용하지 않습니다.

## 알려진 한계

- Claude 스킬 인식은 모델·hook 실행 없이 확인할 구조화 인터페이스를 검증하지 못해 파일·설정 관측까지만 제공합니다.
- Codex 예제 실행은 모든 도구·외부 연결 차단을 보장하는 어댑터가 없어 지원하지 않습니다.
- Claude 예제는 스킬 본문을 직접 제공하는 텍스트 검사입니다. Skill 도구 호출, 참조 파일·스크립트 실행, 실제 업무 성공을 증명하지 않습니다. 비용 상한은 CLI 추정치 기준이며 실제 청구 금액을 엄격히 제한하지 못합니다.
- 진단은 새 터미널 CLI를 대상으로 합니다. 이미 열린 Codex 앱·MCW 세션의 상태를 확인하지 않습니다. 내용 지문 탐색 상한이나 읽기 오류가 발생한 결과도 재확인 필요로 유지합니다.

## 검증

Windows 단위·계약 테스트 453개, 타입 검사와 프로덕션 빌드를 확인했습니다. 임시 홈과 모의 CLI·모델·GitHub 응답을 사용하는 실제 Electron E2E 3건에서 설정 관리, 파일 변경·충돌·복원, 인식 목록·프로젝트 범위·예제 검토·실행과 1280×800·900×600 레이아웃·키보드 탭 이동을 확인했습니다. PC 보고의 민감 정보 제외·동시 전송 충돌·비공개 여부 재확인과 동기화 충돌 후 재검토는 임시 로컬 Git 원격과 모의 GitHub 응답으로 검증했습니다.

현재 PC의 Codex CLI 0.166.0으로 메타데이터만 수동 조회해 스킬 23개와 그중 플러그인 스킬 13개의 경로·플러그인 식별자를 확인했습니다. 실제 모델 호출, 실제 개인 프로필·PC 보고 전송은 실행하지 않았습니다. 상세 계약은 [CLI 인식 진단과 PC 상태 보고](../contracts/cli-recognition.md)를 참고하세요.
