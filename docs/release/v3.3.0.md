# v3.3.0 — 설정 편집기 제거

설정 파일을 통째로 손으로 고치는 **설정 편집기** 화면을 뺐습니다. 설정은 이미 설치(관리 키만 merge)와 가져오기(레포 템플릿으로 끌어오기)가 맡고 있어 따로 둘 이유가 없었습니다.

## 바뀐 점

- 사이드바에서 **설정**이 빠졌습니다. 남은 화면: 상태판·설치·카탈로그·정리·가져오기·외부 API(+ 타이틀바의 셋업 위저드).
- 편집기 전용 코드도 함께 걷어냈습니다: `config:*` 채널, 편집용 백업·복원, provider별 설정 파일 목록, `vanilla-jsoneditor` 의존성. 그 덕에 CSP에서 blob 워커 허용도 뺐습니다.

## 호환성

- v3.2.x에서 자동 업데이트로 올라옵니다. 설정·상태 파일에는 영향이 없습니다.
- 이전 버전 설정 편집기가 `~/.harness-manager/backups`에 남긴 백업 파일은 지우지 않고 그대로 둡니다. 필요하면 직접 열어 보면 됩니다.
- 설정을 직접 고치려면 이제 에디터로 `~/.claude/settings.json`·`~/.codex/config.toml`을 엽니다. 관리 키는 다음 설치 때 레포 값으로 맞춰집니다.

## 검증

- `npm test`: 테스트 파일 45개, 테스트 258개 통과(편집기 테스트를 빼고 IPC 테스트는 다른 채널로 옮김)
- `npm run typecheck`, `npm run build` 통과
- 개발 앱에서 사이드바 6개 화면을 차례로 열어 오류 배너 없음 확인
