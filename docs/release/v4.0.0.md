# v4.0.0 — Claude·Codex 환경을 한 작업대에서 관리

구성요소 / 환경 / 변경 내역 / 프로필을 중심으로 UI를 재구성했습니다. 스킬·지침·MCP·mod를 선택하면 양쪽 CLI의 설치·활성·인식·실행 검증 상태와 근거를 나란히 확인합니다.

- **공통 스킬·지침:** 한 프로필에서 양쪽 적용 대상을 고르고, 프로필 저장과 실제 PC 적용을 각각 미리보기로 검토합니다. 기존 로컬 문서를 가져오거나 GitHub 저장소의 스킬을 발견·가져올 수 있습니다.
- **버전과 업데이트:** GitHub의 정확한 커밋, 문서 해시, 적용 파일 해시를 기록합니다. 일반 문서 업데이트는 조건부 자동 적용하며 실행 코드·플러그인 패키지는 수동 검토합니다.
- **변경 이력·복원:** 파일 변경의 전후 해시와 복구 저널을 남깁니다. 새 파일은 삭제 대신 보관하며 이후 사용자 편집이 있으면 복원을 중단합니다. 복원 후에는 다음 수동 적용까지 자동 쓰기를 보류합니다.
- **자동 관리:** 전환한 개인 프로필 전체의 일반 문서가 대상입니다. 앱 실행 중 로컬 변경·원격 업데이트를 확인하며, CLI 실행 중이거나 상태를 확인하지 못하면 자동 쓰기를 보류합니다. 수동 작업이 우선합니다.
- **진단:** hook 중복·제한 시간·MCW 소유 설정과 프로젝트/전역 차이를 읽기 전용으로 확인합니다. MCP는 승인 후 초기화 연결만 검사하며 도구·모델 요청은 보내지 않습니다. Claude mod 5개의 Codex 대응 방식과 한계를 표시합니다.
- **기존 기능:** 설치·가져오기·정리·외부 API는 환경 화면에서 접근합니다. 기존 doctor/install/capture 명령을 유지하고 `hm components`, `updates`, `history`, `restore`를 추가했습니다.

## 전환과 호환성

기존 프로필은 자동 전환하지 않습니다. 개인 프로필을 선택한 뒤 **v4 전환·정책 검토**를 실행하세요. 기존 정의·PC 설정·백업은 보존합니다. 공통 기본은 읽기 전용입니다.

v4 구성요소가 있는 이동 파일은 bundle version 2입니다. 기존 version 1도 읽습니다. v3 앱으로 돌아갈 때는 전환 이전 백업을 사용하세요. 로그인·인증 파일은 프로필에 포함하지 않습니다.

CLI 자체 업데이트·고정 버전을 받지 않는 설치기는 재현 가능한 버전 pin을 보증하지 않습니다. SDK hook의 동적 동작·신뢰 승인·현재 열린 세션의 실행도 정적 검사만으로 확인하지 않습니다. 프로젝트는 읽기 전용이고 MCW 설정의 소유권은 유지합니다.

## 검증

Windows에서 66개 파일·349개 단위·계약 테스트, 타입 검사·빌드를 통과했습니다. 격리된 실제 Electron E2E도 2회 연속 통과했습니다. E2E는 프로필 생성 → 공통 스킬 → 양쪽 파일 적용 → 일반 문서 자동 갱신 → 이력 → 복원을 검증하며 OS 프로세스 조회만 격리합니다. 별도 테스트에서 실행 중·조회 실패 시 자동 보류를 확인합니다. 실제 계정·유료 모델은 사용하지 않았습니다.

MCP는 격리된 stdio 프로세스와 모의 HTTP 응답으로 초기화·종료를 검사합니다. GitHub 다운로드는 고정 응답으로 커밋 고정·링크 거절·잘린 트리·오류 처리를 검사합니다. 원격 프로필 수신은 로컬 Git 원격 픽스처로 검증합니다. 실제 외부 스킬 설치·CUA 설치·회사 프로필 변경은 실행하지 않았습니다.
