# v3.4.0 — 주황 테마

앱의 주색을 청록에서 **주황**으로 바꿨습니다. 같은 계열이던 multi-cli-work(청록)와 한눈에 구별되고, 앱 아이콘·배너의 주황과도 맞습니다.

## 바뀐 점

- 강조색(선택된 사이드바·탭·주 버튼·포커스 테두리·링크)이 주황입니다. 다크 `#e8825f`, 라이트 `#b4532f`.
- 바탕 회색을 초록빛에서 따뜻한 회색으로 바꿨습니다. 다크·라이트 두 테마 모두.
- 상태색(초록·노랑·빨강)과 provider·분류 배지 색은 그대로입니다.
- 토큰 이름을 `--teal`에서 `--primary`로 바꿨습니다.

## 호환성

- v3.3.x에서 자동 업데이트로 올라옵니다. 설정·상태 파일에는 영향이 없습니다.

## 검증

- `npm test`: 테스트 파일 45개, 테스트 258개 통과
- `npm run typecheck`, `npm run build` 통과
- 개발 앱에서 6개 화면과 위저드·상세 대화상자를 다크·라이트로 캡처해 대비와 깨짐 확인
