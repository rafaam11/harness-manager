# v5.1.1 — Codex 공용 스킬 표시와 첫 GitHub 동기화 수정

Codex에 설치한 스킬이 HM 목록에서 빠지는 문제와 비어 있는 GitHub 저장소에 처음 프로필을 보내지 못하는 문제를 수정했습니다.

- **Codex 스킬 목록:** `~/.agents/skills`의 공용 스킬도 읽습니다. 기존 `~/.codex/skills` 조회는 유지하며, 링크된 스킬은 실제 대상을 기준으로 한 번만 표시합니다. 깨진 링크와 순환 링크는 건너뛰고 스킬 안의 소스 자료까지 재귀 탐색하지 않습니다.
- **첫 GitHub 동기화:** GitHub CLI가 빈 저장소의 기본 브랜치를 빈 이름으로 반환해도 새 저장소로 처리합니다. 첫 보내기 미리보기와 업로드가 정상 동작하며, 원격 변경·충돌 검사는 유지합니다.
- **실패 원인 표시:** `git -c 실패` 대신 `git clone`·`git rev-parse`처럼 실제 실패한 동작과 종료 코드 또는 시간 초과를 표시합니다. 오류 출력은 길이를 제한하고 인증 정보는 가립니다.

## 호환성

프로필·이동 파일 형식과 기존 설정은 바뀌지 않습니다. 이번 수정만으로 프로필을 자동 업로드하거나 다시 설치하지 않습니다. 다른 PC에도 같은 동작을 적용하려면 앱을 업데이트하세요.

## 검증

Windows에서 단위·계약 테스트 383개, 타입 검사와 프로덕션 빌드를 확인했습니다. 격리된 실제 Electron 화면에서 공용 스킬 4개와 Qt 스킬의 목록·상세 표시 및 문서 읽기를 확인했습니다. 임시 Git 원격으로 빈 브랜치 응답의 첫 업로드와 인증 정보가 가려진 실패 메시지를 검증했고, 실제 연결된 비공개 빈 저장소에서도 파일 12개·충돌 0개의 보내기 미리보기를 확인했습니다. 실제 개인 프로필은 업로드하지 않았습니다.
