# v4.1.0 — 프로필을 몰라도 쓰는 환경 관리

기본 화면을 **이 PC / 동기화 / 변경 기록 / 앱 설정**으로 나눴습니다. 스킬·지침을 바꿀 때는 한 번 검토한 뒤 내 설정 저장과 PC 적용을 함께 처리합니다.

- **이 PC:** 이름·종류·Claude·Codex 상태를 36px 목록으로 압축했습니다. 창 높이에 맞춰 페이지당 행 수를 바꾸고, 선택한 항목의 설정·진단·기록을 탭으로 확인합니다. 작은 창에서는 상세를 겹쳐 엽니다.
- **첫 편집:** 개인 사본 생성이나 v4 전환을 따로 진행하지 않습니다. 첫 적용에 저장소 준비를 포함하며, 파일 쓰기가 실패하면 원래 선택과 PC 파일을 복구합니다. 기존 개인 설정의 자동 적용 정책은 유지합니다.
- **변경 검토:** 적용 대상과 변경 범위를 먼저 보여 주고 파일 차이·명령·경로는 자세히에서 엽니다. 기준 설정과 PC 파일을 같은 저널에 기록하고 함께 복원합니다. 이후 사용자 수정이 있으면 중단합니다.
- **동기화:** 연결 상태와 보낼 변경·받을 변경을 한 화면에서 확인합니다. 수신 전에 병합한 기준 설정과 PC 변경을 함께 검토합니다. 외부 설치가 일부 실패하면 기준 저장을 보류하고 완료·실패 항목을 기록합니다.
- **변경 기록:** 짧은 목록에서 결과를 선택해 복원 범위를 확인합니다. 자동 적용 정책은 앱 설정으로 옮겼습니다.
- **앱 설정:** 문서 자동 적용과 고급 유지 관리를 모았습니다. 여러 프로필·폴더 연결·원본 파일 편집은 고급 설정에서 사용합니다. 전역 프로필 선택 바와 반복 안내는 제거했습니다.

## 호환성과 동기화

기존 프로필 ID, 이동 파일과 doctor/install/capture·workbench CLI 계약을 유지합니다. 고급 원본 편집과 기존 CLI의 기준 저장은 기존 방식대로 동작합니다. 원격 업로드는 수동입니다.

외부 설치 명령은 자동 복원하지 않습니다. 실패한 수신은 변경 기록을 확인한 뒤 다시 검토하면 남은 작업을 실행합니다. 양쪽에서 같은 파일을 바꾼 충돌은 고급 프로필에서 해결합니다. 로그인·인증 파일은 복사하거나 전송하지 않습니다.

## 검증

Windows에서 66개 파일·357개 단위·계약 테스트, 타입 검사·프로덕션 빌드를 통과했습니다. 격리된 실제 Electron E2E에서 첫 편집 → 한 번 검토 → 양쪽 CLI 파일 적용 → 동시 편집 충돌 차단 → 기준·PC 동시 복원 → 고급 설정 접근 → 검색·페이지 전환을 확인했습니다.

1280×800과 900×600, 125% 확대에서 목록의 바깥 스크롤과 적용 버튼 위치를 검사했습니다. 원격 병합·PC 적용·복원은 로컬 Git 원격으로 검증하고, 외부 설치 실패 시 기준 저장을 보류하는 경우도 검사했습니다. 테스트 홈·GitHub 설정과 프로세스 조회를 격리하며 실제 계정이나 유료 모델을 호출하지 않습니다.
