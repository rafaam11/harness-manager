# v3.1.0 — 외부 API 화면

jk-external-api(한국 외부 정보원 색인)를 앱 안으로 옮겼습니다. 사이드바의 **외부 API**에서 공공·외부 정보원과
그것을 쓰는 k-skill, 생활 문제 청사진, 기술을 한곳에서 찾습니다.

## 새 기능

- **정보원 탭**: 통합 검색(이름·설명·키워드·데이터 필드·기술)과 분야·제공 방식·인증·실시간성·지역 필터. 목록과 관계 노선도를 바꿔 볼 수 있습니다.
- **비교**: 정보원을 최대 4개 담아 인증·비용·형식·갱신·지역·CORS·기술을 한 표에서 비교합니다.
- **k-skill·청사진·기술 탭**: 검색, 분류 필터, 정렬, 페이지 나누기가 있습니다.
- **상세**: 기록 하나를 대화상자로 엽니다. 데이터 명세, 접근 조건, 연결된 k-skill·청사진·기술을 보여 주고, 연결 항목은 같은 대화상자에서 열립니다("뒤로"로 돌아감). 공식 서비스·개발 문서·이용조건 링크는 OS 브라우저로 엽니다.
- **스냅샷 새로고침**: k-skill 목록을 GitHub에서 다시 받습니다. 받은 목록이 형식에 맞을 때만 저장하고(`~/.harness-manager/external-api/skills.json`), 실패하면 기존 스냅샷을 그대로 씁니다.
- **공식 링크 점검**: 정보원 공식 링크가 살아 있는지 확인합니다.

## 바뀐 점

- 원 레포의 공개 사이트, 실시간 미리보기 Worker, 주간 자동 PR은 가져오지 않았습니다. 미리보기는 사용자 API 키를 앱에 저장해야 해서 뺐습니다.
- k-skill 귀속(MIT)과 정보원 이용조건 안내는 `THIRD_PARTY_NOTICES.md`에 있습니다.

## 호환성

- v3.0.0에서 자동 업데이트로 올라옵니다. 기존 설정·상태에는 영향이 없습니다.
- 앱에는 v3.1.0 시점의 k-skill 스냅샷(116개)이 들어 있습니다. 최신 목록은 "스냅샷 새로고침"으로 받습니다.
