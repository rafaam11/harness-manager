# v3.7.0 — 사용자 프로필 이동과 상태판 개선

사용자 프로필을 소스 레포 없이 관리하고 다른 PC로 옮길 수 있습니다. 상태판과 설치 결과에는 더 큰 아이콘과 상태 요약을 추가했습니다.

## 사용자 프로필

- 공통 기본 정의를 앱에 포함해 소스 레포 없이 진단과 설치 계획을 사용할 수 있습니다.
- 앱에서 개인 프로필을 편집하고 미리보기 후 저장할 수 있습니다. 저장만으로 PC 설정이 바뀌지는 않습니다.
- 프로필을 파일로 내보내고 가져올 수 있습니다. 인증 정보와 PC 고유 절대경로는 이동 대상에서 제외합니다.
- 선택적으로 비공개 GitHub 저장소에 프로필을 보내거나 받을 수 있습니다. 동기화 전 변경 사항과 충돌을 확인합니다.
- 기존 legacy 설정은 원본을 보존하며 개인 프로필로 이전합니다.

## 화면 개선

- 상태판에 영역별 아이콘과 정상·주의·누락·정보 요약을 추가했습니다. 위저드에도 같은 아이콘을 적용합니다.
- 설치 결과에서 실패 항목과 복구 옵션을 먼저 확인할 수 있습니다. 복구 후 결과를 다시 반영합니다.
- 사이드바와 외부 API 탭의 아이콘을 보강했습니다. 화면 전체 개선은 후속 작업으로 이어집니다.

## 검증

- Windows에서 Vitest 60개 파일·320개 테스트, 타입 검사와 프로덕션 빌드를 통과했습니다.
- Node 런타임 테스트가 실제 PC의 NVM 경로에 영향을 받지 않도록 테스트 경로를 격리했습니다. 실제 설치 보호 기준은 유지합니다.
- 새 UI의 실제 Electron 화면 검토와 실제 원격 GitHub 프로필 동기화는 이번 검증에서 수행하지 않았습니다.

## 업데이트

- 기존 앱에서 자동 업데이트하거나 이 릴리스의 설치 파일을 실행하세요.
