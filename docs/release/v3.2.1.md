# v3.2.1 — 레포 자동 연결

설치본을 처음 띄웠을 때 상태판이 "레포 클론 위치를 모릅니다"에서 멈추던 문제를 고쳤습니다.

## 바뀐 점

- **레포를 스스로 찾습니다**: 기록된 위치가 없으면 Claude의 `jinmin` 마켓플레이스가 가리키는 레포 폴더, 그다음 `~/dev`·`~/source/repos`·`C:\dev`·`D:\dev` 같은 흔한 폴더 아래 `harness-manager`를 찾아 기억합니다.
- **"레포 받기" 한 번으로 연결**: 그래도 없으면 경고 배너 대신 연결 카드가 뜹니다. 버튼 하나로 공개 레포를 `~/dev/harness-manager`에 받고 바로 다시 검사합니다. 그 폴더에 다른 파일이 있으면 받지 않고 알립니다. "이미 있는 폴더 선택"도 그대로 있습니다. 상태판·설치·가져오기·위저드가 같은 카드를 씁니다.
- **실행 중 경고는 필요한 화면에만**: "실행 중인 provider" 경고를 파일을 쓰는 화면(설치·정리·설정 편집기·위저드)에만 띄웁니다.
- 타이틀바 업데이트 배지의 버튼 글자가 두 줄로 꺾이던 문제를 고쳤습니다.

## 호환성

- v3.2.0에서 자동 업데이트로 올라옵니다. 이미 레포 위치를 기억한 PC는 달라지는 것이 없습니다.
- "레포 받기"에는 git이 있어야 합니다. 없으면 설치 안내를 보여 줍니다.

## 검증

- `npm test`: 테스트 파일 46개, 테스트 264개 통과(레포 탐색·클론 테스트 6개 추가)
- `npm run typecheck`, `npm run build`, `electron-builder --win --dir` 통과
- 패키지 앱(`release/win-unpacked`)을 빈 임시 홈으로 띄워 연결 카드 확인 → "레포 받기"로 실제 클론 → 상태판 카드 8개 표시까지 확인
- 실제 홈에서 기록 없이 자동 탐색만으로 찾는 경우는 단위 테스트로만 확인
