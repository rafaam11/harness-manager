## 프로젝트 문서 컨벤션

- 이 사용자의 프로젝트는 `AGENTS.md`를 source of truth로 삼는다. Claude Code용
  `CLAUDE.md`는 `@AGENTS.md`를 import하는 얇은 래퍼일 뿐이며 실제 내용은 없다.
- 작업 시작 시 프로젝트 루트의 AGENTS.md를 최우선으로 확인한다.

## 세션 인계 (Handoff)

- 작업 디렉터리 루트에 `HANDOFF.md`가 있으면 세션 시작 시 최우선으로 읽는다. 그
  브리핑(목표/진행상황/결정사항/다음 단계)을 신뢰하고 처음부터 다시 묻지 않는다 —
  불명확한 부분만 되묻는다. 언급된 브랜치/변경 파일은 `git status`/`git diff`로
  직접 재확인한 뒤 이어간다.
- 작업을 완전히 마치면 `HANDOFF.md` 상단에 "처리완료"를 표시하거나 파일을 삭제한다.
